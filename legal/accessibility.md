# Accessibility Statement

**Effective date: 12 September 2026**

## Our commitment

We want the futureclips to be usable by as many people as possible, including people with disabilities.

## Standard

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

## What we have done

- Semantic HTML structure and landmark regions
- Keyboard navigability throughout the interface
- Visible focus indicators on interactive elements
- Text alternatives for meaningful images
- Colour contrast meeting AA thresholds for body text and interface elements
- Respect for reduced-motion preferences
- Responsive layouts supporting zoom and varied screen sizes

## Known limitations

Some generated Output may not include automatic text alternatives. We are working to improve this. Some third-party embedded components may not fully conform to our standard.

## Feedback

If you hit an accessibility barrier, email **team@thefutureclips.com** with a description of the issue and the page it affects. We aim to respond within 5 business days.
