What changed from the last set

The gym carousel was marked down as too dark, too uniform, and one design language repeated. Each of those is a specific, checkable thing rather than a matter of taste — so each got a specific answer.

  • Too darkPhotography is filtered on measured luminance before it enters the pool — anything under a mean of 118 is discarded. Four of the six grounds are saturated colour; two are paper. Nothing in the set is near-black except one half of the closing frame.
  • All the sameNo layout is reused. The compositions are: bleed circle, two-column dot comparison, arch with an oversized numeral, centred dial, labelled photograph, horizontal split.
  • Same design languageNew typefaces, not the ones used all session: Bricolage Grotesque for the shouting, Instrument Serif italic answering it, JetBrains Mono for labels. New niche, new brand, new palette.

What the build refuses to ship

Five of these six were written because they caught something in this set.

  • Glyph coverageEvery string is checked against its own face before it renders. Instrument Serif has no superscript two, and one missing glyph makes resvg fall the entire run back to the default family — so "2 mg/cm²" quietly set in the grotesque beside its serif sibling.
  • Overlap assertionText boxes assert they are clear of the elements around them. fitText guarantees copy fits its own box and knows nothing about the photograph next to it, so a paragraph ran underneath one and lost the end of every line.
  • Sticker boundsA sticker sizes itself from its label, so a long label walked off the right edge and through a headline. Bounds now include the lift the rotation adds.
  • Translucency gateengine/source/cutout.mjs had the gate and the measurement but never connected them — stats never carried the field, so the check silently skipped and five see-through face mattes reported "pass". Now wired.
  • Negation-aware claimsThe banned-claims check flagged "waterproof" in the line "nothing is waterproof" — punishing the copy for being accurate. It now looks back for a negator before deciding a term was asserted, and still catches the asserted form.
  • Derived countsThe headline says six places because it counts the array beneath it.

Matting was tried and rejected — every candidate failed the translucency gate between 0.20 and 0.97 against a 0.06 limit. Bright skin on a bright ground gives the model no edge to find. So the photography is cut into geometry instead, which is what collage actually is, and which cannot half-fail.
